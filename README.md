# EcoFuturo

## Descripción
EcoFuturo es una aplicación web educativa y de gestión ambiental desarrollada para promover la cultura del reciclaje y el cuidado del medio ambiente. Permite a los profesores crear temas educativos, publicar actividades y evaluar las entregas de los estudiantes con calificaciones y observaciones, mientras que los estudiantes pueden consultar contenidos, interactuar con actividades y llevar un registro de su progreso académico[cite: 1, 2].

## Cómo ejecutar el proyecto
1. Copiar la carpeta `EcoFuturo` en el directorio de publicaciones local: `C:\xampp\htdocs\`[cite: 1, 2].
2. Abrir **XAMPP Control Panel** e iniciar los servicios de **Apache** y **MySQL**[cite: 2].
3. Ingresar al navegador e ir a `http://localhost/phpmyadmin/`[cite: 2].
4. Crear una nueva base de datos o importar directamente el archivo `database/proyecto_reciclaje.sql`[cite: 1, 2].
5. Verificar o ajustar los parámetros de conexión en el archivo `config/conexionBDD.php` si es necesario[cite: 1].
6. Abrir en el navegador la dirección: `http://localhost/EcoFuturo/`[cite: 2]
